# 🏥 Hospital Management System

A **Hospital Management System** web application designed to manage core hospital operations such as patient registration, doctor management, appointments, and basic administration. This project is developed as part of an  learning project with a focus on backend logic, database connectivity, and real-world workflow simulation.

---

## 📌 Project Overview

The Hospital Management System helps automate day-to-day hospital activities and reduces manual work. It provides a structured way to store and manage data related to patients, doctors, and hospital services.

This project demonstrates the use of **Java, JSP, Servlets, JDBC, and MySQL** to build a dynamic and database-driven web application.

---

## ✨ Features

* 👨‍⚕️ Doctor Management
* 🧑‍🤝‍🧑 Patient Registration
* 📅 Appointment Management
* 🔐 Login & Authentication
* 🗂️ Database Connectivity using JDBC

## ⚙️ Installation & Setup

1. Clone the repository

   ```bash
   git clone https://github.com/SrujalAudarya/Hospital-Management.git
   ```

2. Open the project in **NetBeans / Eclipse**

3. Import the database:

   * Create a MySQL database
   * Import `hospital.sql`

4. Update database credentials in `DbConnection.java`

5. Deploy the project on **Apache Tomcat Server**

6. Run the project and access it via browser
